# live-metrics-dashboard

Real-time metrics dashboard over WebSockets.

> Status: planned. This repository holds the project outline, and the code is on its way.

## Overview

A dashboard that streams service metrics to the browser in real time and keeps a short rolling history for each chart.

## Planned features

- WebSocket stream with reconnect and backpressure
- Line, bar and gauge widgets
- Configurable layouts saved per user
- Alert thresholds with visual highlights

## Tech stack

TypeScript, React, WebSockets, Node.js
